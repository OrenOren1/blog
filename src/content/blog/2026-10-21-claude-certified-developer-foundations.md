## TL;DR

I earned the **Claude Certified Developer - Foundations** badge from Anthropic, issued through Credly. It's a foundations-level credential covering how to build with Claude correctly — prompting, tool use, and the agentic patterns I already lean on daily in platform and DevOps work.

## Introduction

I've been using Claude and Claude Code as a working tool for a while now — not as a novelty, but wired into real pipelines: architecture docs, presentation generation, infrastructure reviews, JIT access tooling. Getting the Foundations badge wasn't about learning something brand new; it was about putting a stake in the ground that the patterns I already use — careful prompting, tool-calling, agentic workflows — line up with how Anthropic itself says these systems should be built and operated.

## What the Badge Covers

The Foundations credential is scoped to the fundamentals: how Claude models actually behave, how to structure prompts and context so the model does what you mean, and how tool use and agent loops work under the hood rather than as a black box. For anyone already building agentic workflows — MCP servers, custom tools, multi-step automation — it's a useful checkpoint: it confirms the mental model you've built from practice matches the documented one.

## Why It Matters for DevOps and Platform Work

AI-assisted engineering is moving from "chat with a model" to "run agents against real infrastructure" — the exact space I work in: Terraform/Pulumi changes, Okta and Atlas administration, CI pipelines that now include an LLM in the loop. Having a formal foundation under that work matters for the same reason any infrastructure certification matters: it's not about the paper, it's about forcing a pass over the fundamentals so the shortcuts you've picked up from experience don't quietly drift from how the tool is actually meant to be used.

## Conclusion

Small milestone, but a real one — official confirmation that the way I've been building with Claude holds up against Anthropic's own foundations. More to come as I go deeper into the agentic and tool-use side of this.
